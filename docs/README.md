# What is in `docs/`

What each file is and whether it is current, then which record of change is
for whom. `README.md` at the top of the repository is where to start;
nothing here is needed to query the database.

| File | What it is | Status |
|---|---|---|
| `ANNOUNCEMENT-DRAFT.md` | Drafts of the next release's notes and the first announcement post, for the maintainer. | Draft: nothing in it has been published. |
| `BUILD-NOTES.md` | What changed in each version, what it exposed, what was deliberately not done. Newest first. | Current, but written by hand, so its newest entry can lag the latest release. |
| `COMMERCIAL-READINESS.md` | Which rows this project may publish, and the licence reading that rests on. | Current; `verify.py` checks every count it marks as a figure. |
| `DECISIONS.md` | The full reason behind each `[D-nn]` rule in `CLAUDE.md`, `CONTRIBUTING.md` and the loop's skills. | Current. Nothing is deleted; a reversed decision says so. |
| `DERIVED-CONFIDENCE.md` | How `confidence` is derived rather than declared. | Partly built; its opening says which steps shipped. |
| `GITHUB-SETUP.md` | The repository's description, website and topics on GitHub. | Current. |
| `LANDED.md` | What landed and what was declined before the queue moved to GitHub Issues on 2026-09-13. | Closed: since then, closed issues and merged pull requests are the record. |
| `LOCAL-SETUP.md` | Running the backlog loop on your own machine. | Current. |
| `MEASUREMENT.md` | Whether anybody arrives: the analytics beacon, the Search Console tag, and what each can tell. | Current. |
| `TIMING-ARCHITECTURE.md` | Why the four timing tables are empty. | Decided. |
| `UPSTREAM.md` | What depends on F1DB, and the plan if it stops, changes shape or changes licence. | Recorded. |
| `design-system.md` | The design system web work is held to. | Adopted, version A. |
| `critiques/` | The outside critiques, by date; each is the reasoning behind the issues it filed. | Each describes the project on its date, not now. |
| `prose_pass.tsv` | The prose pass's reading of each prose field. | Generated by `tools/prose_pass.py`; do not edit. |
| `backlog_issue_map.json` | Each id in the retired `docs/BACKLOG.md` and the issue it became. | Written when the queue moved; nothing reads it now. |

## Which changelog

| Where | What it says | For |
|---|---|---|
| [lapledger.org/changes](https://lapledger.org/changes) and its `feed.xml` | What moved in the data, for each published state — a release or a refresh. | Anyone using the data. |
| The GitHub release | The files of a tagged release, their licences and digests, then the pull requests merged since the last tag. | Anyone downloading them. |
| `BUILD-NOTES.md` | What each version changed in the build, and why. | Anyone working on the build. |
| Closed issues, and `LANDED.md` before 2026-09-13 | Each piece of work, with its pull request or the reason it was declined. | Anyone working on the project. |
